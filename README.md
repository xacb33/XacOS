# XacOS

![screenst](<Captura de pantalla 2026-07-07 000315.png>)

This is a very bare-bones WebOS simulator to present myself.
The main objective was to learn HTML, JavaScript and CSS, so expect the code to be a mess...

## What's new in 1.0
1. Fixed bugs, like the windows changing shape when dragged to the right corner of the screen

2. Revamped settings: you can now add your own wallpaper, change the font of the whole OS and see some information about your PC

3. Added very simple notes app 

4. Start menu: access it by clicking the XacOS logo in the corner of the taskbar, see and open all of your apps

# Functions

## Welcome screen
![screenshot](welcomescreenshot.png)
The first screen that you encounter when starting up. (You can also open it clicking Welcome in the start menu) 
It is the main introduction to myself, citing some facts about me.

## Projects app
![explorerlogo](explorer.png)
Here you can explore a couple of projects I've made by double clcking the icons

## Settings app
![settingslogo](settings.png)
By clicking the 3 lines menu icon, you can choose to change the wallpaper, the font or see information about your PC. You can also set your own image as the wallpaper!

## Taskbar
The taskbar shows the time, the OS name and the icons of your open programs.
You can click them to bring up the window

## Sticky notes app
A very simple app that allows you to type whatever you want. Brainstorm, write your grocery list, etc. but remember it does not save into local storage!

## Start menu
By clicking into the XacOS text in your taskbar, you can see and open all available apps in your XacOS.
